# cruz-del-sur-console-app
Aplicación de consola en Java para la gestión de transporte y venta de pasajes de Cruz del Sur.

## Funciones

- Ver rutas
- Comprar pasajes
- Mostrar precios
- Menú interactivo

## Tecnologías usadas

- Java
- Scanner
- Bucles
- Condicionales
- Funciones
- Records

## Cómo ejecutar

1. Abrir el proyecto en VS Code
2. Ejecutar Main.java
